# صدای هوشمند | sedaye-smart

سامانه مستقل و جدا از `balepanel` برای مدیریت هوشمند گروه «صدای کارکنان ثبت احوال».

## فناوری
Next.js · Supabase · Vercel · PostgreSQL / RLS

## اجرا
npm install
npm run dev

متغیرهای `.env.local` را از روی `.env.example` تنظیم کنید.

این پروژه مستقل است و نباید کد یا تنظیمات `balepanel` را تغییر دهد.
